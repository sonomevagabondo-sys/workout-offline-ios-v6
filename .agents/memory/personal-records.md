---
name: Personal record interpretation
description: Product rules for PR dates, recent performance, and muscle-group balance.
---

Only completed workout data counts toward a PR. Show the best recorded load with its repetitions and date, and label estimated one-rep max as an estimate. Rate performance against the user's own recent sessions and compare muscle-group balance against the active program's planned weekly sets, not universal strength norms. Clearly label missing or insufficient history.

**Why:** The app does not collect enough personal information to make valid population-level strength claims, while the user still wants actionable feedback.

**How to apply:** Keep comparisons personal and plan-relative; do not call a user weak, strong, or medically imbalanced based only on these metrics.
